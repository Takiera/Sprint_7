# Яндекс Самокат — API-тестирование

**Java · REST Assured · JUnit 4 · Allure**

Учебный проект Яндекс Практикума.

Проверка API сервиса аренды самокатов: создание, авторизация и удаление курьера, оформление заказов и получение списка. Проект сочетает позитивные и негативные условия с параметризацией вариантов заказа.

## Подход к тестированию

- **Негативные условия:** дубликаты, отсутствие обязательных полей и неверные учетные данные.
- **Параметризация:** четыре варианта массива цвета заказа.
- **Проверки API:** HTTP-статусы, поля JSON и тип списка заказов.
- **Связанные действия:** создание курьера, получение ID и удаление.
- **Разделение слоев:** данные, модели, API-шаги и assertions организованы отдельно.
- **Allure:** названия и шаги помогают читать сценарии в отчете.

## Технологии

- Java;
- JUnit 4;
- REST Assured;
- Allure.

## Что проверяется

### Курьер

- Создание курьера с корректными данными.
- Повторное создание курьера.
- Создание без логина или пароля.
- Авторизация с корректными данными.
- Авторизация с неверным логином или паролем.
- Авторизация без логина.
- Удаление созданного курьера.

### Заказы

- Создание заказа с цветом BLACK, GREY, обоими цветами или пустым массивом цвета.
- Получение списка заказов с проверкой HTTP-статуса и структуры поля `orders`.

Ожидания по HTTP-статусам и полям ответа заданы в существующих проверках.

## Структура ветки develop

```text
src/main/java/data/            # адреса и исходные данные
src/main/java/model/           # модели запросов
src/main/java/steps/           # действия с API
src/test/java/                 # сценарии и базовые классы
pom.xml                        # зависимости и Allure
```

## Запуск

Скачайте исходники `develop`, распакуйте их и откройте терминал в каталоге с `pom.xml`.

```bash
mvn test
```

Базовый адрес API задан в `src/main/java/data/CourierData.java`.

## Allure

Для формирования или локального просмотра отчета по существующим результатам:

```bash
mvn allure:report
mvn allure:serve
```
